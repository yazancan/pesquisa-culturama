# Culturama

Projeto desenvolvido durante a formação de front-end da Alura, com foco em construção de layouts e organização de conteúdo.

## 🚀 Tecnologias
- HTML
- CSS

## 💡 Funcionalidades
- Estruturação de páginas com diferentes seções
- Exibição de conteúdos culturais
- Layout organizado e responsivo

## 🧠 Aprendizados
- Uso de HTML semântico
- Organização de layout com CSS
- Boas práticas de estruturação de páginas
